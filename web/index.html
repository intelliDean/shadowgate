02 / RELEASE GATE

Require recovered behavior

The release command must return a nonzero exit code when payment and delivery violate the tested policy.

npm run gate -- --profile recovered

The baseline gate is deliberately expected to fail for reproduced exposure.

What the integration must provide

Connect locally runnable components through the supported adapter. The runner needs the real payment path to produce meaningful evidence.

  • Facilitator verification and settlement routes.
  • A protected resource with an observable result.
  • A local RPC endpoint and temporary test identities.
  • Explicit fee and payment-delivery expectations.

Keep the proof bounded

Use the baseline to reproduce the failure and the recovered profile to verify the correction. Compare both against actual ledger state.

  • Signed transfers use valueless local tokens.
  • No mainnet keys or production funds are required.
  • Success claims apply to executed scenarios only.
  • Uncertain outcomes must remain visibly uncertain.
